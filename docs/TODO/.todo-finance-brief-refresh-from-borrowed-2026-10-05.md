## 1. 根因

`widget_tree_insert_child_deep` 只**追加** widgets 到 graph（`insert_child` 的 replaced_same_name 逻辑只在 LiveId 名字相同时替换）。它**不会**主动移除 Splash 已有的、LiveId 不再匹配的旧 children。

结果：click 后 Splash 的 graph children 列表同时包含 launcher outer View + news_list outer View（如果 LiveId 名字不同），但 `refresh_node_children_from_discovered` 的"keep"逻辑保留 manual 且 alive 的旧 entries —— 加上 `retired` 仍持有 OLD widgets 直到 fn 返回，`upgrade().is_some()` 返回 true，旧 children 不被清理。

`/d` dump 显示 Splash → 旧 outer View 树，导致 `/snap`/draw 都看到 launcher 内容。

## 2. 正确路径

`WidgetTree::refresh_from_borrowed(uid, visit)` (widget_tree.rs:1065-1119)：
- 直接调 `refresh_node_children_from_discovered(uid, ..., discovered_children, false)`
- 传入 `mark_structure_dirty=false`，但 `refresh_node_children_from_discovered` 自己会在 parent_changed 时 set `inner.structure_dirty=true`
- 然后会被 `sync_dense` → `rebuild_dense` 触发 `/d` dump 看到新内容

关键区别：`refresh_from_borrowed` 通过 `refresh_node_children_from_discovered` 完整做"发现 → diff → 移除旧 → 添加新"，而 `widget_tree_insert_child_deep` 只做"添加"。

新（保留 `retired` retire 步；把 `insert_child_deep` 换成 `refresh_from_borrowed`）:
```rust
            let mut new_children: Vec<(LiveId, WidgetRef)> = Vec::new();
            host.children(&mut |id, child| new_children.push((id, child)));
            drop(host);
            // Retire the previous view's children (overlay draw lists + subtree).
            for (_, child) in retired.children.iter() {
                retire_widget_tree(cx, child);
            }
            // Refresh the widget tree from the live host widget so the graph
            // diff-discovers / drops OLD children whose LiveId names don't
            // match the new view's children. `insert_child_deep` only adds;
            // it never reconciles. (`refresh_from_borrowed` is the public
            // surface of `refresh_node_children_from_discovered` — see
            // `widget_tree.rs:1065-1119`.) Walking the live widget after
            // `mem::replace` is exactly the precondition the doc comment
            // names: "call this when the subtree is not borrowed."
            cx.widget_tree().refresh_from_borrowed(host_uid, |visit| {
                for (id, child) in &new_children {
                    visit(*id, child.clone());
                }
            });
            cx.widget_tree_mark_dirty(host_uid);
            view_set = true;
```

注意：
- 保留 `let mut new_children: Vec<(LiveId, WidgetRef)> = Vec::new();` 收集 host.children 那一段
- 保留 `drop(host);` 释放 borrow
- 保留 `for (_, child) in retired.children.iter() { retire_widget_tree(cx, child); }` retire 步
- **替换** for-loop `widget_tree_insert_child_deep(...)` 为单次 `refresh_from_borrowed(host_uid, |visit| { ... })`
- `cx.widget_tree().refresh_from_borrowed(...)` —— `cx.widget_tree()` 返回 `&WidgetTree`，`.refresh_from_borrowed(...)` 是 pub 方法
