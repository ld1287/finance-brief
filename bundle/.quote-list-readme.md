# quote_list.card rewrite notes (2026-10-03)

`quote_list.octoscript` (Phase 2 widget-tree, 屏 #7) rewritten to true L0
ledger `quote_list.card`, mirroring `launcher.card` (5 段顺序 + Surface 包裹)
and the stock.card / news.card dashboard / feed-list idiom.

5 段顺序: `source` → `state` → `event` → `copy` → `view`

- 4 主题 chip 共享 1 个 `enum[a, us, fx, crypto]` state (`selected_tab`),
  `active:` 由 `selected_tab == .x` 驱动 — 4 个 host-fetched source 互不冗余
- `selected` (text) 给 K线跳转留口: "" ⇒ 列表, ticker ⇒ 详情 (后续 kline.card
  接 `open_kline` 事件)
- 列表 4 分支用 `when selected_tab == .x { for ... }` 切换数据源, 字段对齐
  stock.card `for m in movers` 范式 (TextRow + TextValue ×2 + TextCaption +
  Rule)
- capability 绑定: `a_quotes/us_quotes/fx_quotes/crypto` 都来自同一
  `sys.quotes(tab:)` host capability (按 `capabilities.toml` 的 `quotes.tab`
  维度), `watch` 来自 `watchlist` capability
