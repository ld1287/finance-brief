# launcher.card rewrite notes (2026-10-03)

Phase 2 wrote 12 screens using a widget-tree dialect (`View { ... }`, `Label`,
`flow:`, `width: Fill`, `{{state.x}}` placeholders, `|| nav.push("...")`
closures) that the L0 parser does NOT accept. The real L0 syntax lives in
`octoscript/crates/octoscript-ui-l0/tests/fixtures/*.card`.

This file documents `launcher.octoscript` → `launcher.card` so the remaining
11 screens follow the same pattern.

## .bak naming convention

Old screen files are renamed, never deleted:

    finance-brief/bundle/<name>.octoscript
      → finance-brief/bundle/<name>.octoscript.bak-pre-card-rewrite-2026-10-03

The suffix `pre-card-rewrite-<YYYY-MM-DD>` is fixed by date. Benefits:

- bulk cleanup: `find . -name '*.bak-pre-card-rewrite-2026-10-03' -delete`
- per-screen restore: `mv *.bak-pre-card-rewrite-* *.octoscript`
- no ambiguity vs other backups — date stamps one rewrite window

## .octoscript → .card differences

| 概念            | .octoscript (旧, 错误)                | .card (新 L0 ledger)                |
|-----------------|---------------------------------------|-------------------------------------|
| 顶层容器        | `View { ... }`                        | `Surface(pad: .page) { ... }`       |
| 行/列容器       | `View { flow: Down/Right }`           | `Col { ... }` / `Row(gap: N) { }`   |
| 文本 widget     | `Label { text: "..." }`               | `TextTitle / TextBody / TextCaption`|
| 可点击卡片      | `View { on_tap: \|\| nav.push(...) }` | `Card(on_tap: <event>, value: <v>)` |
| 文本值引用      | `"{{state.x}}"` 占位符                | 直接 path: `state.x` / `copy.foo`   |
| 事件触发        | 闭包 `\|\| ...`                       | 命名 event + widget `value:` 传参   |
| 状态/事件/文案  | host 注入 (implicit)                  | `state` / `event` / `copy` 段显式   |
| 加载/错误状态   | (无)                                  | `when source.$state == .pending`    |
| 列表迭代        | state.list + index                    | `for x, i in source key x.id { }`   |

## launcher.card 结构

5 段顺序: `source` → `state` → `event` → `copy` → `view`

- 7 个导航 event 全部 `set($value)`，把 Card 传过来的 screen id 写入 `selected`
- 9 条 `copy` 文案 (hdr / news / res / quote / fav / set / stream / ds / ft)
- 顶层 view 用 `Surface(pad: .page)` 包裹, 子 view 通过裸名引用
- 6 主 tile + 1 backup tile = 7 个 `Card`, 布局对应原 launcher 第 6-9 行注释
