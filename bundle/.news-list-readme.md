# news_list.card rewrite notes (2026-10-03)

`news_list.octoscript` 改写为 L0 `.card` ledger，对齐 `launcher.card` 5 段顺序 +
`Surface(pad: .page)` 包裹 + 严格 widget 集。原文件改名备份为
`news_list.octoscript.bak-pre-card-rewrite-2026-10-03`（保留，不删除）。

## 段序 & capability 绑定

`source` (3: lead/feed/env.locale) → `state` (1: selected) → `event`
(2: open_story/back) → `copy` (5: masthead/src/back_lbl/loading/offline) → `view`。

- `lead` / `feed` 都走 `sys.news(...)`，feed 用 `offset: 1` 跳过 lead，对应
  news.card "TWO sources, not one sliced two ways" 原则。
- `state.selected` 仅承载路由标记：`""` 留在本屏，非空 = 已点条目 id，由
  `news_detail.card` 读取渲染 — 本屏不写 `story` view，避免越权定义 detail 屏。
- 加载/失败由 `when feed.$state == .pending / .failed` 走 `copy.loading /
  copy.offline`，与 news.card `view stream` 同源。
- `event open_story` 触发后由 host 把 control 转交给 `news_detail.card`
  （capabilities.toml 中的 `screen: news_detail`），本屏不引用 detail view。
