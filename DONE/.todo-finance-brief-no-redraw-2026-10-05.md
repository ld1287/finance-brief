## 0. 现象
- `cargo run --release --bin finance-brief` 弹出 440×1400 的 makepad 窗口
- 但窗口内空白 / 没有渲染任何 launcher 卡片
- 日志只有：`finance-brief MOUNT route=launcher src_len=28377 built=true`，无 `[E]` 报错

## 1. 根因
对比 sister project：
- `Octoscript-Makepad/apps/flutter-samples/src/lib.rs:474` → mount 末尾有 `cx.redraw_all();`
- `Octoscript-Makepad/apps/kit-host/src/main.rs:625` → mount 末尾有 `cx.redraw_all();`（还有 836 / 845 / 885 多处）

finance-brief `apps/desktop/src/app.rs` 的 `App::mount()` 在 `host.view = view;` 之后**没有调用 `cx.redraw_all()`**。结果是 view 写进了 Splash，但 makepad 不知道要重画，窗口停留在初始空白状态。

补充：finance-brief/apps/desktop/src/app.rs `handle_event` 里 re-mount 分支加了 `cx.redraw_all()`，但**首次 mount 不走 handle_event** — mount 函数自身要负责触发首次 redraw（与 kit-host / flutter-samples 一致）。

## 2. 改动 1：在 `mount()` 末尾加 redraw_all
- 文件: `apps/desktop/src/app.rs`
- 位置: `App::mount()` 内 `if let Some(view) = built_view { ... host.view = view; ... }` 之后
- 动作: 插入一行 `cx.redraw_all();`
- 草稿（参考 kit-host:625）：
  ```rust
  if let Some(view) = built_view {
      if let Some(mut host) = self.ui.widget(cx, ids!(host)).borrow_mut::<Splash>() {
          host.view = view;
      }
      cx.redraw_all();   // ← 新增
  }
  ```
- 理由: 没有 redraw，窗口停留在初始空白帧。
